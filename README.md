## 📊 Core Quantitative Modules (11 Total)

### 1. Joel Greenblatt’s Magic Formula Screener
* Ranks equity universes quantitatively on **Earnings Yield** ($\text{EBIT} / \text{Enterprise Value}$) and **Return on Capital** ($\text{EBIT} / (\text{Net Working Capital} + \text{Net Fixed Assets})$).
* Enforces institutional sector exclusions (Financial Services & Utilities) and provides interactive 3D scatter positioning matrices.

### 2. McKinsey Key Value Driver & DCF Valuation Model
* Implements McKinsey's core valuation formula linking operational cash flow, perpetuity growth ($g$), Return on New Invested Capital (RONIC), and Weighted Average Cost of Capital (WACC).
* Features interactive 3D surface topology plots and color-coded sensitivity matrices evaluating Enterprise Value across varying macro conditions.

### 3. Economic Profitability & EVA Dashboard
* Computes real-time Economic Value Added ($\text{EVA} = (\text{ROIC} - \text{WACC}) \times \text{Invested Capital}$) and economic return spreads.
* Displays conditional status alerts validating whether a firm is actively creating or destroying shareholder value.

### 4. Momentum & Filter Rule Strategy Scanner
* Executes percentage-based filter rule scans over adjusted daily price histories, tracking running pivot troughs and peaks to generate systematic Long/Cash signals.
* Includes interactive Plotly price-action trend inspection charts.

### 5. Kelly Criterion Portfolio Sizing Engine
* Calculates optimal geometric compounding allocation fractions ($f^*$) based on win probability ($p$) and win/loss ratios ($b$).
* Provides both **Full Kelly** and institutional **Half Kelly** allocations to mitigate drawdown volatility.

### 6. Black-Litterman Macro Allocation Matrix
* Combines market cap equilibrium excess returns ($\Pi = \delta \Sigma w_{\text{mkt}}$) with explicit macroeconomic tactical investor views ($P, Q, \Omega$).
* Eliminates Mean-Variance Optimization (MVO) corner solutions and extreme weight sensitivities across multi-asset global universes.

### 7. AURA-AEGIS Geopolitical Risk Engine
* Models sovereign asset freezes, capital controls, and sanctions using Hawkes jump-diffusion point processes and Topological Data Analysis (TDA) 2-Wasserstein distances.
* Automates emergency multi-trust custody migration and synthetic asset wrapping when seizure probability exceeds critical thresholds.

### 8. CHRONOS-LIQUIDITY Dark Pool Router
* Solves institutional block order fragmentation across dark pools using Quadratic Unconstrained Binary Optimization (QUBO) and simulated quantum annealing.
* Masks order routing parameters using Zero-Knowledge Proof (ZKP) micro-parcels to eliminate predatory HFT signal leakage and market impact.

### 9. NEMESIS-ALPHA Behavioral Contagion Control
* Computes real-time Shannon behavioral entropy ($H_{\text{human}}$) from decision latencies, NLP boardroom sentiment, trade revision frequencies, and biometric stress indicators.
* Engages an automated fiduciary override protocol during acute market panics to freeze destructive, fear-driven liquidations.

### 10. Macro Stress Tests & Monte Carlo VaR Simulation
* Performs 10,000-path multivariate normal Monte Carlo simulations to forecast 30-day 99% Value-at-Risk (VaR) and Expected Shortfall (ES).
* Conducts instant macro stress testing across duration-based yield curve spikes (+50 to +400 bps) and liquidity freeze volatility expansions.

### 11. Alpha & Capital Preservation Impact Analytics

## 🚀 Local Installation & Execution

To run the unified suite locally on your machine:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/souravhossanofficial-cmd/quant-investment-suite.git
   cd quant-investment-suite
   ```

2. **Create a Virtual Environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Launch the Streamlit Terminal**:
   ```bash
   streamlit run app.py
   ```
