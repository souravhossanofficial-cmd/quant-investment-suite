## 🚀 Local Installation & Execution

To run the full suite locally:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/souravhossanofficial-cmd/quant-investment-suite.git
   cd quant-investment-suite
   ```

2. **Create a Virtual Environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **(Optional) Enable Enterprise Infrastructure**:
   * **Redis**: Ensure a local Redis server is running on `127.0.0.1:6379` for Phase 1 telemetry.
   * **CUDA GPU**: Install the appropriate CuPy package for your CUDA toolkit version (e.g., `pip install cupy-cuda12x`) for Phase 2 acceleration.

5. **Launch the Terminal**:
   ```bash
   streamlit run app.py
   ```
